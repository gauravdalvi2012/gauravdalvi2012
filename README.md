## 🧠 What I Build

I like taking ideas from **zero → working software** — designing the system,
building the interface, connecting the backend, and getting it into the hands of users.

- ⚡ **Modern web applications** with React, TypeScript, Next.js, and thoughtful frontend architecture
- 🧩 **Developer tooling & build systems** with Webpack, CLI tooling, reusable abstractions, and automation
- 🔌 **Backend services & APIs** with Node.js, Express, Java, REST, and OpenAPI
- 🎨 **Interactive browser experiences** with Three.js, React Three Fiber, Canvas, WebGL, and animation
- 🤖 **AI-powered products** integrating generative models into real applications and workflows
- 📱 **Application development** across modern web and Android

> I like understanding what happens beneath the abstractions — then building better abstractions.
